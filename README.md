# Algoritmo de Arañas Sociales para la formulación de la solución nutritiva

Código del proyecto de fin de carrera. Cada carpeta es un proyecto independiente con su propio manual.

| Carpeta | Lenguaje | Contenido |
|---|---|---|
| `SSA_Basico/` | C++ | Algoritmo de Arañas Sociales adaptado (resultados 2 a 6) y sus pruebas unitarias |
| `Generador_Instancias/` | Python | Generador de instancias, calibración de parámetros y experimentación numérica (resultados 7 a 10) |
| `Recocido_Simulado/` | C++ | Recocido simulado con que se compara el algoritmo en la experimentación |
